# MVP 测试计划

版本：`v1`  
日期：2026-03-07

## 1. 目标
1. 验证 MVP 范围内功能可用且行为稳定。
2. 在发布前发现高风险缺陷并阻断上线。
3. 用统一门禁标准支撑 Go/No-Go 决策。

## 2. 范围
覆盖范围：
1. 后端统一 REST + WebSocket 接口。
2. Codex Adapter 参考实现。
3. 前端会话列表、时间线、设置页、连接测试能力。
4. 运行时配置读取与本地覆盖机制。

不在本阶段：
1. 多租户账号体系。
2. 云端托管与分布式部署。

## 3. 测试环境矩阵
1. 开发环境：本地单机（Linux/macOS/Windows）。
2. 集成环境：单节点部署（后端 + 静态前端）。
3. 浏览器：Chrome 最新稳定版、Safari 最新稳定版、移动端 Chrome/Safari。

## 4. 测试分层与责任
1. 单元测试（Owner：开发）
   - 统一模型映射、参数校验、错误码映射、配置解析。
2. 集成测试（Owner：开发 + QA）
   - API 到 Adapter 的链路联通、鉴权、分页、续接流程。
3. 端到端测试（Owner：QA）
   - 前端操作到流式事件展示的真实闭环。
4. 非功能测试（Owner：开发 + QA）
   - 性能、稳定性、安全基线。

## 5. 核心功能用例

| 用例ID | 场景 | 预期 |
| --- | --- | --- |
| E2E-01 | 进入会话列表页 | 成功加载适配器与会话列表 |
| E2E-02 | 切换适配器 | 列表按适配器维度刷新 |
| E2E-03 | 打开会话详情 | 历史事件按时间线展示 |
| E2E-04 | 发起 continue | 收到流式增量并最终完成 |
| E2E-05 | WebSocket 中断重连 | 可恢复并继续接收事件 |
| E2E-06 | 设置页修改地址 | 保存后生效，刷新后保持 |
| E2E-07 | 连接测试按钮 | 成功时给出明确成功状态 |
| E2E-08 | 配置恢复默认 | 恢复为 runtime 默认配置 |
| E2E-09 | token 错误 | 显示鉴权失败并给出修复提示 |
| E2E-10 | 目标会话不存在 | 返回标准错误并可回到列表 |

## 6. 非功能测试基线
1. 性能：
   - 会话列表接口目标：`p95 < 300ms`（中等规模数据）。
   - 继续会话后首帧事件目标：`< 1s`（本地网络条件）。
2. 稳定性：
   - 连续 30 分钟订阅不崩溃、无明显内存泄漏。
   - 适配器异常退出可被捕获并返回标准错误。
3. 安全：
   - 未鉴权请求不可访问受保护接口。
   - 日志不出现 token、密钥、个人路径。

## 7. 缺陷等级与处理
1. `S0`：安全或数据泄漏，必须阻断发布。
2. `S1`：核心路径不可用，必须阻断发布。
3. `S2`：有替代路径或局部影响，可评估延期修复。
4. `S3`：体验问题，可纳入后续迭代。

## 8. 进入与退出标准
进入标准：
1. API 契约冻结（至少候选版本）。
2. 核心功能开发完成并可部署。
3. 测试数据与环境可用。

退出标准：
1. `S0/S1` 缺陷为零。
2. 核心 E2E 用例全部通过。
3. 适配器一致性测试通过。
4. 发布清单关键项已完成并有证据链接。

## 9. 交付产物
1. 测试报告（通过率、失败项、风险结论）。
2. 缺陷列表与优先级。
3. Go/No-Go 建议结论。
