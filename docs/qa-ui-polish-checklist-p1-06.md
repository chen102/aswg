# QA 预置清单：TASK-P1-06（UI Polish）

日期：2026-03-07  
状态：`IN_PROGRESS`（待 DEV 提交 `docs/dev-ui-polish-p1-05.md` 后执行）

## 1. 桌面端可用性

1. 会话侧栏卡片化样式清晰，`active` 态与默认态可区分。
2. 聊天气泡层级清晰，`user/assistant` 角色对比可读。
3. 输入区固定底部策略生效，长会话滚动时输入区不遮挡消息。
4. 发送中/禁用态可感知（按钮、输入框或状态文本）。

## 2. 移动端断点

1. `<=960px` 断点下主布局无溢出与遮挡。
2. 会话列表/详情区切换可操作，关键按钮可点击。
3. 长文本气泡自动折行，不出现横向滚动条。

## 3. 交互态与状态可读性

1. `hover/active/disabled` 样式符合可访问性预期（可见差异）。
2. 错误态（如 `4010/4003/网络失败`）文案可读且不破坏布局。
3. 状态提示与消息线程分区明确，不回退为原始事件日志视图。

## 4. 证据要求

1. 桌面端截图至少 2 张（会话列表 + 聊天区）。
2. 移动端截图至少 2 张（列表区 + 聊天区）。
3. 关键交互态截图至少 2 张（active/disabled/error 任意组合）。

## 5. 计划输出

完成后提交：`docs/qa-ui-polish-p1-06.md`，包含逐项 `PASS/FAIL`、证据路径、最终 `Go/No-Go`。
