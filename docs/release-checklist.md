# 发布清单（Release Checklist）

版本：`v1`  
日期：2026-03-07

## 1. 使用说明
1. 每次版本发布前按本清单逐项勾选。
2. 每项应有责任人和证据（PR、报告、截图、日志链接）。
3. 关键项未完成时，不允许进入发布步骤。

## 2. 角色定义
1. Release Owner：发布负责人，主持 Go/No-Go。
2. Dev Owner：功能与缺陷修复负责人。
3. QA Owner：测试与质量门禁负责人。
4. Ops Owner：部署、监控与回滚负责人。
